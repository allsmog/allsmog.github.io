zkdpop-go

// Go · Applied crypto

zkdpop-go is a Go framework for interactive Schnorr zero-knowledge authentication, short-lived JWTs, DPoP key binding, and ready-to-use middleware.

open repository all work

Where it fits

Applied cryptography, authentication, and proof-of-possession access control.

What stands out

  • Interactive Schnorr ZK login primitives.
  • JWT verification bound to client DPoP keys.
  • Reference auth server and middleware for Go services.

Related areas

zkdpop-go connects to cryptography, authentication, dpop, jwt, zero-knowledge-proofs. The source repository carries the code, releases, issues, and documentation trail.
